# v0.1.40 Release Runbook

## Objective
- Execute `v0.1.40` release in one pass with repeatable preflight, publish, and verification steps.

## Preflight
- `git checkout main`
- `git pull --rebase`
- `git status -sb`
- `cargo fmt --check`
- `cargo test -q`
- `cargo clippy -- -D warnings`
- `make smoke-post-release`

## Tag and Publish
- `git tag -a v0.1.40 -m "v0.1.40: runtime reliability and release-flow continuity"`
- `git push origin v0.1.40`
- `gh release create v0.1.40 --title "v0.1.40" --notes-file docs/release/v0.1.40-draft.md`

## Verify
- `gh release view v0.1.40 --json name,tagName,url,publishedAt`
- `gh release view v0.1.40`

## Post-Release Follow-Up
- Update `Cargo.toml` to next development version.
- Sync `Cargo.lock` if version metadata changed.
- Log release/smoke evidence and references in `docs/changelog.md`.
