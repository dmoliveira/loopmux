# v0.1.44 Release Runbook

## Objective
- Execute `v0.1.44` release in one pass with repeatable preflight, publish, and verification steps.

## Preflight
- `git checkout main`
- `git pull --rebase`
- `git status -sb`
- `cargo fmt --check`
- `cargo test -q`
- `cargo clippy -- -D warnings`
- `make smoke-post-release`

## Tag and Publish
- `git tag -a v0.1.44 -m "v0.1.44: runtime reliability and control-path hardening"`
- `git push origin v0.1.44`
- `gh release create v0.1.44 --title "v0.1.44" --notes-file docs/release/v0.1.44-draft.md`

## Verify
- `gh release view v0.1.44 --json name,tagName,url,publishedAt`
- `gh release view v0.1.44`

## Post-Release Follow-Up
- Update `Cargo.toml` to next development version.
- Sync `Cargo.lock` if version metadata changed.
- Log release/smoke evidence and references in `docs/changelog.md`.
