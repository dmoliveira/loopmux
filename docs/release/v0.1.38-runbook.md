# v0.1.38 Release Runbook

## Objective
- Execute `v0.1.38` release in one pass with clear preflight, publish, and verification checkpoints.

## Preflight
- `git checkout main`
- `git pull --rebase`
- `git status -sb`
- `cargo fmt --check`
- `cargo test -q`
- `cargo clippy -- -D warnings`
- `make smoke-post-release`

## Tag and Publish
- `git tag -a v0.1.38 -m "v0.1.38: redraw-gating reliability and telemetry polish"`
- `git push origin v0.1.38`
- `gh release create v0.1.38 --title "v0.1.38" --notes-file docs/release/v0.1.38-draft.md`

## Verify
- `gh release view v0.1.38 --json name,tagName,url,publishedAt`
- `gh release view v0.1.38`

## Post-Release Follow-Up
- Update `Cargo.toml` to next development version.
- Sync `Cargo.lock` if version metadata changed.
- Log release/smoke evidence and references in `docs/changelog.md`.
