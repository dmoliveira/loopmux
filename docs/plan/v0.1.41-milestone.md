# v0.1.41 Milestone Plan

## Objective
- Deliver the next reliability-focused iteration after `v0.1.40` with stronger loop-state visibility and stable control-path behavior.

## Scope
- Tighten observability signals that help operators distinguish healthy progression from long idle windows.
- Expand deterministic regression coverage for hold/resume and cadence-sensitive transitions.
- Keep release artifacts (`draft`, `runbook`, `changelog`) continuously aligned during card execution.

## Proposed Work Items
- `Card 1` Runtime signal refinement
  - Improve signal readability for long-running sessions under mixed active/idle patterns.
  - Preserve low-noise cadence defaults while keeping enough detail for incident triage.
- `Card 2` Regression defense growth
  - Add focused tests for hold/stop cadence paths and control-state edge behavior.
  - Keep transitions deterministic under strict formatting/lint/test gates.
- `Card 3` Release-flow continuity
  - Maintain v0.1.41 draft/runbook/changelog references as milestone PRs merge.
  - Keep release commands and post-release housekeeping steps ready to execute.

## Acceptance Criteria
- Milestone cards are tracked in `br` with concise scope and validation evidence.
- Quality baseline remains green: `cargo fmt --check`, `cargo test -q`, `cargo clippy -- -D warnings`.
- Release docs are internally consistent and executable at cut time without ad-hoc command discovery.

## Out of Scope
- Broad feature-area expansion unrelated to runtime reliability.
- CLI-breaking contract changes.

## Future Backlog
- Remote tmux session discovery over SSH (opt-in with host allow/deny controls): `docs/specs/remote-tmux-ssh-discovery.md`.
