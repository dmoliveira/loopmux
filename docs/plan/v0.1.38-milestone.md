# v0.1.38 Milestone Plan

## Objective
- Deliver a small reliability-and-operations milestone after `v0.1.37` with measurable runtime observability and release repeatability.

## Scope
- Improve render/runtime observability without increasing operator noise.
- Tighten release documentation quality and cutover consistency.
- Add one targeted regression-defense pass for recent TUI cadence logic.

## Proposed Work Items
- `Card 1` TUI cadence telemetry refinement
  - Add bounded telemetry visibility for redraw skip behavior in logs/docs.
  - Keep live output concise while preserving operator diagnostics.
- `Card 2` Regression-defense tests
  - Add focused tests for redraw-gating edge cases and stop-state interactions.
  - Ensure deterministic behavior under compact/standard/wide paths.
- `Card 3` Release flow polish
  - Keep release draft/runbook/changelog references synchronized through release cut.
  - Validate end-to-end release commands in one documented sequence.

## Acceptance Criteria
- Milestone cards are tracked in `br` with clear deliverables and validation notes.
- Quality baseline stays green: `cargo fmt --check`, `cargo test -q`, `cargo clippy -- -D warnings`.
- Release docs (`draft`, `runbook`, `changelog`) remain mutually consistent at cut time.

## Out of Scope
- Major architecture rewrites or framework migration.
- Breaking CLI behavior or config schema changes.
