# v0.1.39 Milestone Plan

## Objective
- Deliver a focused runtime-confidence milestone after `v0.1.38` with stronger observability and predictable release readiness.

## Scope
- Refine redraw telemetry semantics so operational signals remain actionable.
- Expand regression coverage around redraw/stop-state behavior in long-running sessions.
- Keep release docs and cutover commands synchronized as cards land.

## Proposed Work Items
- `Card 1` Telemetry signal quality
  - Tune redraw-skip telemetry wording/cadence for clearer operator interpretation.
  - Ensure telemetry remains low-noise while preserving incident debugging value.
- `Card 2` Runtime regression hardening
  - Add tests for redraw suppression edge cases during stop/resume style transitions.
  - Guard deterministic rendering expectations across layout variants.
- `Card 3` Release-flow continuity
  - Maintain aligned `draft`, `runbook`, and `changelog` references for v0.1.39.
  - Validate release command sequence and post-release housekeeping traceability.

## Acceptance Criteria
- Milestone cards are tracked in `br` with concise scope and validation evidence.
- Quality baseline remains green: `cargo fmt --check`, `cargo test -q`, `cargo clippy -- -D warnings`.
- Release docs stay internally consistent at release cut time.

## Out of Scope
- Broad architecture migration or CLI schema breakage.
- Nonessential UI redesign unrelated to runtime reliability.
