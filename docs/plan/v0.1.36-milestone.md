# v0.1.36 Milestone Plan

## Objective
- Ship a focused quality/maintainability milestone after `v0.1.35` with lightweight operational improvements.

## Scope
- Harden release ergonomics and repeatability.
- Improve smoke validation confidence for tmux-backed runs.
- Capture one focused runtime reliability pass in the loop engine.

## Proposed Work Items
- `Card 1` Release automation polish
  - Add a scripted post-release tmux smoke helper and document usage.
  - Add a short release checklist and keep it aligned with actual commands.
- `Card 2` Runtime reliability pass
  - Reduce edge-case hangs around trigger readiness and one-shot send completion.
  - Add/adjust tests for bounded completion behavior.
- `Card 3` TUI/operator UX follow-up
  - Improve stop-state visibility and final status lines in compact/standard layouts.
  - Keep output deterministic for snapshot-friendly validation.

## Acceptance Criteria
- All milestone cards are tracked in `br` with clear owner-facing descriptions.
- Validation baseline remains green: `cargo fmt --check`, `cargo test -q`, `cargo clippy -- -D warnings`.
- At least one real tmux smoke run is captured and logged per release cycle.

## Out of Scope
- Large architecture migrations or UI framework replacement.
- Breaking CLI surface changes.
