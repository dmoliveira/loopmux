# v0.1.44 Milestone Plan

## Objective
- Deliver the next reliability-focused iteration after `v0.1.43` with clearer runtime diagnostics and stable loop-control behavior.

## Scope
- Improve operator-facing telemetry clarity for long-running loops.
- Expand deterministic regression coverage for cadence and state transitions.
- Keep release artifacts (`draft`, `runbook`, `changelog`) synchronized as cards merge.

## Proposed Work Items
- `Card 1` Runtime signal refinement
  - Improve heartbeat diagnostics readability with minimal log noise.
  - Keep cadence context explicit for faster triage.
- `Card 2` Regression defense growth
  - Add focused tests for telemetry output contracts and cadence edge paths.
  - Preserve deterministic behavior under strict formatting/lint/test gates.
- `Card 3` Release-flow continuity
  - Keep v0.1.44 draft/runbook/changelog references current as PRs land.
  - Keep release and post-release commands ready to execute.

## Acceptance Criteria
- Milestone cards tracked in `br` with concise scope and validation evidence.
- Quality baseline remains green: `cargo fmt --check`, `cargo test -q`, `cargo clippy -- -D warnings`.
- Release docs are internally consistent and executable at cut time.

## Out of Scope
- Broad feature work outside runtime reliability.
- CLI-breaking contract changes.

## Future Backlog
- Remote tmux session discovery over SSH (opt-in with host allow/deny controls): `docs/specs/remote-tmux-ssh-discovery.md`.
